# Security Policy

## Supported Versions

Repositories in this organization are maintained on a rolling basis; the latest
state of the default branch is the supported version.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use one of the following private channels:

- **GitHub private vulnerability reporting** — open the repository's **Security**
  tab and choose **Report a vulnerability** (preferred).
- **Email** — zhaoxinghua09@gmail.com

Please include: the affected repository and commit/version, a clear description
of the issue, steps to reproduce, and any proof-of-concept material.

We aim to acknowledge reports within **5 business days** and to provide a status
update within **15 business days**. Reporters who wish to be credited will be
acknowledged unless anonymity is requested.

## Scope

This policy applies to all repositories under this organization.
